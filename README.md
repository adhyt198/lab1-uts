# lab1-uts
📚 BukuKita – Website Toko Buku Online
📖 Deskripsi

BukuKita adalah website toko buku online sederhana yang dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web 1.

Website ini dirancang untuk memudahkan pengguna dalam melihat katalog buku, memeriksa stok, melakukan checkout, dan melihat status pengiriman pesanan.

✨ Fitur Website
Login: Halaman masuk ke website.
Dashboard: Menampilkan halaman utama dan informasi katalog buku.
Informasi Stok: Menampilkan daftar buku dan informasi ketersediaan stok.
Checkout: Halaman untuk melakukan proses pemesanan buku.
Tracking: Menampilkan informasi status pesanan dan pengiriman.
🛠️ Teknologi yang Digunakan
HTML5 – Membuat struktur halaman website.
CSS3 – Mengatur tampilan dan desain website.
JavaScript – Menambahkan fungsi dan interaksi pada website.
